# Trilha de prompts para utilizar no Google Gemini
**Observação importante:** estes são prompts preparados para execução. Não são transcrições nem respostas atribuídas ao Gemini. Execute em https://gemini.google.com/ e capture evidências reais se a disciplina exigir comprovação.

**Prompt 1 — Contexto:** "Sou estudante do primeiro semestre de Engenharia de Software. Estou implantando um PortfolioHUB acadêmico usando GitHub Pages, HTML, CSS e JavaScript. Atue como revisor técnico, identifique dúvidas e mantenha um plano por etapas."

**Prompt 2 — Planejamento:** "Analise estas seis etapas de implantação: planejamento, GitHub, usuários e segurança, compartilhamento, testes e apresentação. Proponha um checklist com critérios verificáveis e riscos, sem afirmar que as tarefas foram executadas."

**Prompt 3 — GitHub:** "Revise uma arquitetura de site estático que consulta apenas a API pública do GitHub. Quais práticas evitam divulgar tokens e asseguram uma interface acessível?"

**Prompt 4 — Segurança:** "Avalie esta política de segurança para GitHub Pages, gestão de colaboradores por GitHub e links públicos ao Google Workspace. Diferencie medidas documentadas de controles efetivamente configurados."

**Prompt 5 — Testes:** "Crie cenários de teste manuais para busca, ordenação, resposta offline da API, links externos, responsividade e navegação por teclado. Forneça resultados esperados, não resultados inventados."

**Prompt 6 — Revisão final:** "Considerando um PortfolioHUB publicado no GitHub Pages, elabore perguntas de auditoria e pontos para uma apresentação de cinco minutos. Indique itens que exigem evidência real."

## Registro de execução
Preencher após cada uso: data, prompt, resumo da resposta, recomendação aceita/recusada, mudança produzida, link ou captura da evidência.

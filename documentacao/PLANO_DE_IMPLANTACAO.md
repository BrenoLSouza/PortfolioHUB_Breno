# Plano de implantação — PortfolioHUB
**Responsável:** Breno Lopes Souza | **Escopo:** aplicação estática acadêmica.

| Fase | Ação | Entregável | Verificação |
|---|---|---|---|
| 1 Planejar | requisitos, limites e riscos | plano e cronograma | revisão do escopo |
| 2 Desenvolver | HTML, CSS, JavaScript | site em `docs/` | abrir localmente |
| 3 Integrar | API pública do GitHub e atalhos Google | cards de repositórios e links | rede e navegação |
| 4 Proteger | revisar secrets, links e permissões | política de segurança | inspeção manual |
| 5 Versionar | Git, push e revisão | repositório GitHub | histórico de commits |
| 6 Implantar | GitHub Pages `/docs` | URL pública | acesso externo |
| 7 Avaliar | testes funcionais, visual e acessibilidade | checklist preenchido | evidências |
| 8 Entregar | relatório, PDF e vídeo | material de apresentação | envio na plataforma |

**Riscos:** API indisponível (fallback de exemplos), link incorreto (verificação pós-publicação), exposição de segredos (nunca enviar credenciais), permissão indevida (revisão manual), prazo curto (priorizar implantação e evidências).

**Critérios de aceite:** navegação e responsividade operantes; projetos públicos carregando quando API disponível; nenhuma credencial no código; README e políticas no repositório; URL publicada e vídeo registrado pelo autor.

**Pós-implantação:** revisar mensalmente links e repositórios, acompanhar issues, atualizar documentação, testar páginas após merges.
